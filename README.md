# Sentiment-Analysis-of-Amazon-Product-Reviews
This project performs Sentiment Analysis on Amazon product reviews using Natural Language Processing (NLP) techniques in Python. The objective is to classify customer reviews as Positive or Negative based on review text and analyze customer opinions automatically.
Project Overview

Customer reviews contain valuable feedback that helps businesses understand user satisfaction. In this project, review data is processed and analyzed using NLP libraries such as spaCy and NLTK VADER to detect sentiment polarity.

Features
1.Upload and process Amazon review dataset
2.Clean text data and remove null / blank entries
3.Perform sentiment scoring using VADER Sentiment Analyzer
4.Classify reviews into Positive and Negative categories
5.Analyze word similarity using spaCy word vectors
6.Evaluate model performance using accuracy and classification metrics

Technologies Used
1.Python
2.Pandas
3.NumPy
4.spaCy
5.NLTK
6.Scikit-learn
7.Google Colab
